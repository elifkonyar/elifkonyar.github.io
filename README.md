# elifkonyar.github.io

Personal academic website of Elif Konyar, served at https://elifkonyar.github.io.

The site is a single static page (`index.html` + `stylesheet.css`) based on
[Jon Barron's website template](https://github.com/jonbarron/jonbarron_website).
Edit `index.html` directly to update content; images live in `images/` and the CV in `files/`.
